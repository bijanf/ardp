PAPER_3_v2 manifest
===================

Paper: "A widening limb salinity contrast accompanies the decline of the Atlantic
overturning freshwater transport in ORAS5" (Rostami, Fallah, Hariri, Fu), revised
for the Journal of Climate. Status of this file: 2026-11-05, round-2 revision.

Repository: github.com/bijanf/ardp (public). Paths below are relative to the
repository root. Checksums: PAPER_3_v2/analysis/checksums.sha256 (SHA-256 of every
JSON and CSV file in PAPER_3_v2/analysis; check with
"sha256sum -c PAPER_3_v2/analysis/checksums.sha256" from the repository root).
Python packages: requirements-paper3.txt.

Inputs
------
Input data are not in the repository; the data directory (data/, git-ignored) holds
them. Inputs and access: see the data statement in the manuscript (Table S9).
Stored intermediate fields are in data/results/ (paper3r1_section_*.nc and related).

or the script name in its file name, scripts/analysis_paper3jc_<name>.py.
